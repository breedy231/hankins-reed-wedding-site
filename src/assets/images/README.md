# Image Placeholders

This directory is for wedding images. Add the following images before launch:

## Required Images

- `hero.jpg` - Main hero image for home page (recommended: 1920x1080, optimized for web)
- `couple.jpg` - Couple photo for Our Story page (recommended: 800x800)

## Optimization Tips

1. Use WebP format when possible for smaller file sizes
2. Compress images with tools like TinyPNG or Squoosh
3. Aim for < 200KB per image for fast loading
4. Provide multiple sizes for responsive images if needed
